# frida

Frida-based tools for the jailbroken iOS device. Each subfolder is a
self-contained tool with its own README (and its own build setup, if it needs
one).

- **`ios-dump/`** — decrypt an installed app and pull a decrypted `.ipa` to the
  host. A Frida 17 port of AloneMonkey's `frida-ios-dump`.

More tools will be added here over time.
